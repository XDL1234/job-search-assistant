# 求职助手 v0.3.0-beta.10 · Windows 测试版

下载 `job-search-assistant-0.3.0-beta.10-windows-x64-setup.exe`。首次安装可选择目录，升级后可用原桌面快捷方式。安装包内置桌面工作进程和浏览器组件。安装目录与本机个人资料、投递记录和截图目录独立。 [GitHub Release](https://github.com/XDL1234/job-search-assistant/releases/tag/v0.3.0-beta.10)

## 主要变化

- BOSS 使用内置原生组件连接已登录的 Chrome，工作台显示本地实时画面。旧扩展用户需要按新流程重新连接。 [Chrome 连接说明](../background-browser.md#首次连接)
- 暂停、停止或完成的任务可编辑并继续。确认修改后保留原任务、已用沟通次数和证据。换标签时会核对原筛选，无法还原会提示重新确认。
- 快速沟通识别发送回执后回到原列表继续。消息值守可从工作台单独开启。接收方或来信变化时，已准备的文字回复不会继续发送。
- 新建任务沿用上次填写，网申条件与 BOSS 分开保存。Excel 导出可指定位置，放大预览使用可用窗口空间。历史截图归各自投递记录。

## 验证范围

- Windows 安装版验证覆盖原路径升级、桌面快捷方式、停止后编辑、表单继承、网申配置、Excel 自选保存位置和正常退出。
- 隔离 Chrome 验证覆盖后台绑定、岗位回执后返回列表和聊天在发送前切换时的保护。真实 BOSS 账号的附件发送、问答和官网网申仍待实站验收。发送结果无法核实时，任务会暂停并保留待核查记录。
- Chrome 最小化或把目标切到隐藏标签时画面可能暂时停帧。安装包暂未代码签名，可用附件 `SHA256SUMS.txt` 核验下载完整性。
