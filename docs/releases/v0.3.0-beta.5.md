# v0.3.0-beta.5 测试版（本机构建，尚未发布）

本版将旧 Chrome 扩展与 Python 图像桥接替换为固定 agent-browser 原生运行时，工作台通过本地 JPEG 帧流显示浏览器。正式动作仍单独保存原始 PNG、目标回执和台账。普通使用者无需安装 Python、Node、Rust 或浏览器扩展。

## 使用方式

1. 安装后打开已有 Chrome；在 Chrome 144+ 的 `chrome://inspect/#remote-debugging` 开启远程调试。
2. 应用“设置与帮助”连接 Chrome，处理浏览器原生许可，绑定已登录的 BOSS 标签。旧扩展连接状态不适用于本版。
3. 核对平台城市和筛选，使用已有简历资料，选择实习/校招/正式工作与投递模式。可另填沟通城市；预览确认后从工作台启动。
4. 建议把 BOSS 放在独立正常窗口并保持该窗口的活动标签。窗口可以在后台；隐藏标签、最小化、电脑休眠或退出不能保证继续更新。

升级保留独立存放的资料、历史和证据，不修改原简历。首次启用新运行时需重新连接 Chrome。详见[连接说明](../background-browser.md)。

## 主要变更

- 脚本模式执行确定步骤，不启动模型；AI 模式只对有界真实岗位事实返回结构化判断。JPEG 预览不作为模型输入。
- 城市、求职类型、重复沟通、动态列表来源和发送前事实变化均由脚本检查。小批候选受剩余沟通配额约束，拒绝后继续本页。
- 岗位详情只提取完整职责、任职要求和技能标签；随机城市推荐、HR 活跃状态和公司介绍不再导致岗位重判与重复模型调用。
- 缓存绑定完整判断事实及资料版本；暂停、停止或材料变更阻止旧模型响应产生新动作。模型用量使用服务端实际报告。
- 修复现代聊天识别、可见身份歧义、附件上传跨会话、批量漏页和浏览器重绑定竞态。面试仍始终转人工；不确定的发送不重试。
- 运行时与媒体入口本机认证，流只读；不读取 Cookie，不关闭用户 Chrome。系统静态代理只补入 Codex 子进程，不修改全局设置。
