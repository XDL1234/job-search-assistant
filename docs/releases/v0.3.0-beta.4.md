# v0.3.0-beta.4 测试版

本版修复用户账号真实 BOSS 页面中发现的兼容问题，沿用原有桌面应用与 Chrome 连接器架构。

- 兼容当前双栏岗位卡片：岗位名不混入薪资，公司名与招聘方分开记录，保留旧页面兼容。
- 沟通只点击一次，然后最多等待 8 秒确认目标岗位回执，避免网页响应较慢时过早登记为待核查；暂停、过期、验证与页面变化继续阻断后续操作。
- 导航最多等待 12 秒，岗位详情允许平台调整追踪参数；列表返回仍核对城市、求职类型等查询参数，防止扩大筛选。
- 提供受限的卡片结构诊断，便于定位页面变化；不执行任意页面脚本、不读取登录 Cookie。
- 聊天列表无法识别时明确报错并暂停，避免无声空轮询。

本轮在用户已登录 Chrome 上进行少量实测：验证当前卡片解析、真实滚动加载、实习类型过滤、一次沟通上限和已有记录去重。脚本快速沟通、原生 AI 推荐操作、原生 AI 精筛三个路径各成功开聊一次，均有目标岗位/会话回执及原始截图，完成后全部暂停。曾出现延迟回执，保留待核查后凭目标会话的后续截图核验，没有重复发送。

Python 109 项、扩展 22 项回归检查通过。真实记录、公司与招聘方明细、简历、会话截图仅保留本机，不随源码或安装包发布。

最终安装包在 D 盘中文/空格目录实际升级，安装版在仅保留系统 PATH 的环境下完成启动、独立 worker 导出、连接器启动和退出检查；1857 项资源清单及安装后的程序/连接器与最终构建一致。安装包 SHA-256 为 `67b0f568cb9f97d8319520718938f312e76e19703e83f05bada27bfabf02138b`，已与 GitHub 附件核对。已有连接器的用户升级后须在 `chrome://extensions` 刷新该扩展，单独刷新招聘网页可能仍加载缓存版本。

**当前账号的 BOSS 聊天列表结构尚需适配，自动回复/值守暂不能作为已验收功能开启。** 附件发送、预设问答、面试接管和官网网申仍需对应真实场景验收；本轮没有发送简历附件，没有进行真实网申。开聊成功不代表所有 BOSS 页面或所有公司网申均已兼容。安装包尚未签名。安装与连接步骤见[后台连接说明](../background-browser.md)。
