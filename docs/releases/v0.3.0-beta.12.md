# 求职助手 v0.3.0-beta.12 · Windows 界面测试版

下载 `job-search-assistant-0.3.0-beta.12-windows-x64-setup.exe`。首次安装可选择目录。已安装用户可以原路径升级，并继续使用桌面快捷方式和原有资料、投递记录及截图。

## 界面变化

- 侧栏、连接状态和页面标题采用统一样式。首页指标、当前任务、最近结果和待办更容易扫读。
- 任务列表把筛选和表格排在一起。新建投递、工作台、待办、投递记录与设置优化了表单、操作区和窄窗口布局。
- 工作台让开始、恢复和暂停更容易找到。预览区域更宽，放大入口位于画面上方。截图留档和实时预览继续分开显示。

## 验证范围

本版以合成求职数据验证界面、键盘操作和 Windows 安装升级。快投引擎沿用 beta.10，上一轮快投实站验证候选仍在等待 Chrome 授权。真实账号发信、附件与网申未作为本次界面版的验收内容。安装包尚未代码签名，可用 Release 附件 `SHA256SUMS.txt` 核对完整性。
