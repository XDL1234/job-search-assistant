# 求职助手 0.3.0-beta.1 测试版

这是面向体验和反馈的 **Windows x64 测试版**，不是已完成真实投递验收的稳定版。

2026-10-07 已在当前电脑验证：D 盘中文/空格目录安装、桌面快捷方式、清除开发环境后的独立启动、台账读取、Excel 导出及正常关闭。未执行投递模拟或真实发送。

## 下载与安装

从 [本版 GitHub Release](https://github.com/XDL1234/job-search-assistant/releases/tag/v0.3.0-beta.1) 的 Assets 下载 `job-search-assistant-0.3.0-beta.1-windows-x64-setup.exe`。`Source code` 是源码，普通使用者不需要下载。

运行安装程序，按中文向导选择安装目录（支持 D 盘），安装后从桌面快捷方式或开始菜单打开“求职助手测试版”。安装器提供卸载入口。若电脑缺少 WebView2，安装程序需要联网获取微软运行时。

Python 执行器、所需 Python 依赖、内置 Skill 与 Codex CLI 0.156.1 随包提供。无需安装 Python、Node、Rust、MSVC，也无需手动安装其他 computer-use Skill。第三方许可证随应用安装。

当前安装包未进行代码签名，Windows 可能显示“未知发布者”或信誉提示。请从本仓库 Release 下载，并按附件 `SHA256SUMS.txt` 核对文件；本项目不会要求关闭系统防护。

## 当前能体验什么

- 原生桌面窗口、八页导航、执行器连接设置。
- 任务台账、投递记录、证据图片和 Excel 导出入口。
- 本地演示入口与暂停、恢复、停止机制。**完整 AI 演示流程尚未通过验收**，执行还需要用户登录自己的 Codex/ChatGPT 账号且具有可用额度。
- 消息中心读取待人工事项。

## 已知限制

- 真实 BOSS/公司官网网申尚未在桌面版开放，不能用于无人值守批量投递。
- 资料导入、公司表配置、BOSS 条件、回复规则和应用内人工确认发送尚未完成；对应页面显示“尚未开放”。
- 运行页目前展示全局最近截图，切换任务时请核对标题和时间；不是实时视频。
- 完整 AI 流程此前遇到额度耗尽及连接超时，未作为本次预发布前置条件。按用户要求，当前电脑真实操作验收安排在发布后。
- 本次只针对当前 Windows 电脑做安装启动检查，未声称通过干净电脑、多版本 Windows 或真实招聘平台兼容性验收。
- 暂不提供自动更新。后续下载新版本安装包升级。

个人资料、台账与截图默认保存在用户主目录的 `.job-search-assistant/desktop`，与程序安装目录分开。卸载程序不主动删除这些数据。模型分析需要把相关资料或截图交给模型服务；发布包不包含开发者账号、简历、截图或聊天记录。
