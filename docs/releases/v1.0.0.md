# 求职助手 v1.0.0

这是第一个 Windows x64 正式版。安装后可以使用公司网申导入和任务预览、BOSS 投递任务、执行工作台、待办、投递记录与 Excel 导出。简历支持 PDF 和 DOCX，扫描版 PDF 由内置 OCR 在本机识别。回填结果由用户核对后保存。

## 安装

| 安装包 | 使用场景 |
| --- | --- |
| `job-search-assistant-1.0.0-windows-x64.msi` | 常规安装，使用 Windows Installer，需管理员授权 |
| `job-search-assistant-1.0.0-windows-x64-setup.exe` | 当前用户安装，适合没有管理员权限的电脑 |

1. 在 [GitHub Release](https://github.com/XDL1234/job-search-assistant/releases/tag/v1.0.0) 下载其中一个安装包。
2. 双击安装包，选择安装目录。完成后从桌面或开始菜单打开「求职助手」。
3. 可在 Windows 的「设置 → 应用 → 已安装的应用」中卸载。安装程序当前未做 Authenticode 签名，Windows 可能提示未知发布者。安装前可用 `Get-FileHash -Algorithm SHA256` 核对 Release 中的 `SHA256SUMS.txt`。

适用于 Windows 10/11 x64，需要 WebView2。安装包内含引导器，系统缺少 WebView2 时需要联网下载该运行时。BOSS 操作使用 Chrome，AI 功能需要连接 Codex。

## 从测试版迁移

退出旧版，把正式版安装到单独的目录。使用同一 Windows 账号打开正式版后，会读取 `%USERPROFILE%\.job-search-assistant\desktop` 里的原有资料和投递记录。核对数据后，可在 Windows 的应用列表中卸载「求职助手测试版」。

## 验收范围

本版覆盖公司表导入与任务预览、简历回填和离线 OCR、投递记录读取和 Excel 导出。BOSS 附件发送、招聘方问答和公司官网实际提交仍待实站验收。
