# 求职助手 v1.1.0

## 主要更新

- 公司网申默认「仅填写，我来提交」。AI 从已保存资料填好表单后暂停，保留当前招聘网页供你核对并提交。选择「填写并自动提交」后，AI 按本轮授权核对必填项和附件，再提交一次。回执不明确时标为「待核查」。
- 网申工作台实时预览当前企业标签页。新版公司网申停止新增截图留档，历史截图仍可查看。截图在本机缩放，执行记录按完整消息显示。
- 自动连接求职专用 Chrome。复用 ChatGPT 登录时从账号的模型目录选择可用模型。
- 投递记录默认显示列表，点击记录可打开详情并拖动调整宽度。筛选栏固定在顶部。简历、个人信息、回复规则和连接与诊断可从左侧导航直接打开。
- 补充个人资料字段和奖项等级识别，改进 BOSS 城市、职位分类和行业选择，以及旧版数据与截图路径迁移。

## 安装与升级

| 安装包 | 使用场景 |
| --- | --- |
| `job-search-assistant-1.1.0-windows-x64.msi` | 使用 Windows Installer 安装，需管理员授权 |
| `job-search-assistant-1.1.0-windows-x64-setup.exe` | 当前用户安装 |

适用于 Windows 10/11 x64。需要 WebView2，安装包包含联网引导器。浏览器自动化需要 Chrome，AI 功能需要连接 Codex。

从旧版本升级前请退出求职助手与求职专用 Chrome。安装目录内的 `data` 保存投递记录、个人资料和历史截图。升级前可备份该目录。来自旧测试版的数据迁移方式见 [v1.0.0 发布说明](https://github.com/XDL1234/job-search-assistant/releases/tag/v1.0.0)。

安装包沿用未做 Authenticode 签名的分发方式，Windows 可能提示未知发布者。可使用 PowerShell 的 `Get-FileHash -Algorithm SHA256` 与附件中的 `SHA256SUMS.txt` 核对。

## 验收范围

通过合成招聘页面验证了两种网申模式、动态表单、附件、实时预览、结果待核查与防重复提交。阿里校招、北汽招聘等实站的实际提交仍待验证。
