# 求职助手 0.3.0-beta.2 · 开发测试版

本版重点是资料导入、投递配置与后台浏览器通路开发。真实 BOSS 投递和真实网申仍有未验收部分，不能作为已通过平台兼容性验证的稳定版。

## 更新

- 导入文字 PDF、DOCX、JSON，保留出处，核对后保存不可变资料版本；不改写用户原简历。
- 实习、校招、正式工作分别配置；提供 BOSS 脚本快速沟通、AI 推荐操作、AI 精筛，以及官网公司表入口。
- 新增 Chrome 浏览器连接器：BOSS 标签页可后台操作，脚本模式不调用模型；扩展首次加载需要在 Chrome 确认。
- 新增回复规则配置，保存用户原话和匹配条件；面试、未明确事实保持人工处理。
- 任务预览绑定资料、简历与公司表指纹，结果不明不重发；运行页截图按轮次筛选。
- 打包自动清理已验证的生成资源目录，避免旧依赖残留；安装包附带连接器、执行器和许可证。

## 使用

下载本版 Windows x64 `setup.exe` 安装器，可选择 D 盘目录并创建桌面图标。Python、Node、Rust 开发环境均非使用前置条件。AI 模式需要自己的 Codex/ChatGPT 登录和可用额度。

后台模式的首次连接方法见[浏览器连接说明](https://github.com/XDL1234/job-search-assistant/blob/main/docs/background-browser.md)。应用和 Chrome 需要保持运行，电脑需保持唤醒。当前扩展未上架 Chrome 商店，安装程序不会静默修改浏览器策略。

## 检查与限制

- 已检查：资料提取、九种类型/模式组合预览、回复条件校验、本机原生应用与桥接的启动关闭；原简历保持不变。
- **未通过真实验收：当前用户 Chrome 中的新扩展接入、BOSS 后台实际发送/附件、AI 精筛结果和真实网申。** 用户已允许先完成开发，真实网申留待后续。
- 回复配置不代表后台回复值守和应用内人工发送已经全部接通；这些属于下一轮迭代。
- 页面布局变化可能导致暂停；平台限制和验证需人工处理，不绕过。
- 安装包未签名，发布者显示状态与 beta.1 相同。下载后请核对附件 `SHA256SUMS.txt`。

个人简历、聊天、截图和登录数据不包含在安装包或仓库中。已有用户数据与安装目录分开保存，升级不主动删除。
