# v0.3.0-beta.3 测试版

本版继续完善后台执行。采用 Tauri、React、Python/SQLite 和随安装包提供的 Chrome 扩展；沿用现有账户登录，个人资料、截图和台账保存在本机。

## 新增能力

- 脚本投递支持翻页、滚动加载、返回列表位置恢复与断点记录；保留原城市和筛选条件，重复页面或连续扫描无匹配时停止，不重复沟通。
- 达到沟通上限后进入消息值守。常见问题使用预设原文；需要语义判断时交给已连接的 Codex，未连接时保存待办，避免反复调用模型。
- 面试邀约、混合问题和不确定结果转人工并请求桌面提醒；系统免打扰可能隐藏通知，消息中心会保留待办。
- 简历只在对方索要后，通过受控文件入口上传本轮绑定的原附件。入口、身份或回执不能核实时停止或转人工。
- 消息中心支持原文查看、保存处理意见、接管、打开并核对会话后确认发送；发送与恢复自动回复分别确认，发送不会解除人工锁。
- 发送前后复核会话、最新消息、材料版本和一次性动作。真实 BOSS 专用任务强制通过受控扩展，防止桌面坐标点击绕开记录。
- 修正旧页面“已发送”文案可能误记沟通成功的问题；连接器冷启动改为检查服务就绪，Codex 断线不影响独立脚本任务。AI 回合切换值守时再次核对暂停，不会清除用户刚发出的暂停指令。

## 安装与使用

下载 Release 的 Windows x64 `setup.exe`，可选择安装位置、桌面和开始菜单快捷方式；普通使用者无需 Python、Node 或 Rust。升级保留独立数据目录。安装包尚未签名。

首次须在 Chrome 加载安装目录内的 `browser-extension`，输入应用设置页提供的连接码；后续可操作后台标签页。Chrome 和应用必须保持运行，电脑不能休眠，关闭应用会暂停任务。详见[连接步骤](../background-browser.md)。
