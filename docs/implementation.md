本文记录已实现的 Skill 与 v0.2 面板。桌面应用的设计、接入验证和后续任务见 [文档索引](README.md)，不要将后续设计视为本文已有实现。

## 交付与约束

一个可分发插件包，包含自包含 job-search-assistant Skill、Windows 电脑操作执行器、自动依赖初始化、SQLite 台账、Excel 报告和本地模拟页面。用户提供简历、个人资料及公司 Excel/CSV。每轮确认后执行；BOSS 双模式，首次用平台话术，索要后发附件，面试必须人工接管。所有网申尝试和填写截图留档。

## 决策记录

- 初始实现时目录为空，按用户要求不擅自执行 Git 操作；后续在用户明确要求下连接 GitHub 并提交 v0.2。每次新的提交/推送仍以用户授权为依据。
- 采用标准库 unittest，减少测试依赖；外部桌面输入在本地模拟页面验证，不触碰招聘账号。
- 决策与页面理解由当前 Codex 会话执行，脚本提供确定性的状态与动作接口，不引入独立 API 后台或凭空承诺无人值守。
- 所需操作说明内置为 references，computer use 内置为 scripts；没有经过验证的第三方 Skill 不列为虚构必需依赖。软件包安装到专用虚拟环境。
- 记录数据与源码/插件缓存隔离，防止个人信息被打包分享。原定 AppData 在本机 MSIX 宿主中被重定向到另一磁盘，实际 pip 安装出现 WinError 17；改为用户主目录 `.job-search-assistant`，保留 `--root` 可配置。

- 默认用户目录 `.job-search-assistant` 的首次依赖安装成功，pip check 无依赖冲突。Skill 已安装至用户 `.agents/skills/job-search-assistant`，源码哈希一致。
- doctor 验证 SQLite 与 Excel 报告写入；不把此结果当作桌面可操作证明。
- 真实 Chrome 离线模拟页面已验证：绑定窗口、原始截图、中文和邮箱输入、点击提交出现 LOCAL-001 回执、平台预设首次沟通出现一次；附件发送和回复计数仍为零。
- 本地截图记录于 `.verification/desktop/frames`，未操作任何招聘网站或真实账号。

## v0.2 可视化面板

- 复用 Python 标准库 HTTP 服务、现有 SQLite 和执行接口；不增加 Node、前端框架或后台模型运行依赖。静态资源采用明确分发白名单。
- 页面包含运行概览、带时间的全局最近截图、投递详情/字段来源/证据、人工事项、配置预览确认与 Excel 下载。
- 暂停/停止立即写入数据库；继续/仅值守进入命令队列，执行器下次请求时复核材料。恢复前旧截图失效，实际输入及长文本分段输入再次校验。
- 面试处理意见只保存，不发送，不自动解锁。用户显式恢复时校验消息仍是所查看版本。面板轮询不会更新执行器活动时间。
- HTTP 只绑定 127.0.0.1，API 校验本次随机凭据、Host/Origin，图片读取限制于记录目录。页面用 textContent 渲染外部文字。
- 独立审查发现并修复恢复期间旧输入仍可继续、CLI 仅值守恢复缺少新图门槛、保存时新增草稿丢失。浏览器实测另发现并修复新建任务选回旧轮次。
- `tests/dashboard_browser_smoke.py` 使用已有 Playwright 与本机 Chrome，只访问本地模拟页面。验证暂停、队列恢复、记录筛选、字段及截图查看、面试意见保存、保存期间继续输入、配置授权、新轮次等待状态、Excel 下载和移动端无横向溢出；无浏览器脚本错误。
- 浏览器验收截图保存在 `.verification/dashboard-2505276e/`（仅开发记录，不分发）。PowerShell 启动器语法检查通过，并实际启动默认用户目录面板；未启动招聘操作。
