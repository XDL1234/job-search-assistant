## 实施与验收

- [x] 资料：PDF、DOCX、JSON 本机提取，字段与原文出处，保存不可变版本，允许编辑核对；原简历不修改。
- [x] 配置：实习、校招、正式工作；BOSS 平台推荐、AI 精筛；官网公司表；配置和实际材料绑定，修改材料使原授权失效。
- [x] 低模型开销：重复导航、计数、去重、截图、表格和条件匹配走脚本；可确定的页面步骤串行执行，异常再交 AI；不以固定坐标盲点替代页面识别。
- [ ] 实际执行：连接当前 Chrome 可见页面，按当前筛选条件对各 BOSS 模式少量功能测试；不读取 Cookie/私有接口，不绕过验证；共享动作台账与桌面锁，暂停后无后续输入，结果不明不重发。
- [x] 沟通：平台预设开场白、请求后发指定附件；预设问答严格匹配，面试整条转人工；人工发送与恢复独立。
- [x] 界面：沿用已确认的八页风格，将未开放页面替换为可用表单，运行状态与记录能追溯；必要的新视觉设计可使用 GPT Image。
- [ ] 架构与安装：复用已有领域服务，按页面职责拆分；资源构建不残留旧文件，版本/许可证/数据保留，普通用户无需开发环境。
- [ ] 验证和交付：单元/集成测试、实际安装窗口、当前登录 BOSS 的筛选/投递各模式实测与记录；网申先完成开发和非真实网站检查，真实网申明确待后续验收。审查后提交推送 GitHub，维护版本说明和已知限制。
